# Weekly Plans

주차별로 추가되는 스펙에 맞춰 작업 계획과 체크리스트를 관리하는 공간.

## 규칙

- 한 주차 = 한 파일: `week-NN.md` (zero-padded, 예: `week-01.md`, `week-12.md`).
- 주차 번호와 그 주차 스펙(`spec/` 하위)은 1:1 대응. 새 스펙이 들어오면 즉시 새 `week-NN.md`를 생성.
- 진행 중 주차는 `Status: in-progress`, 완료된 주차는 `Status: done`. 다음 주차로 넘어가도 이전 파일은 유지(회고/누적 컨텍스트).

## 파일 구조 템플릿

각 주차 파일은 다음 섹션을 포함한다:

```markdown
# Week NN — {짧은 제목}

- Status: in-progress | done
- Spec: spec/{해당 주차 파일들}
- Started: YYYY-MM-DD
- Completed: YYYY-MM-DD (완료 시)

## 목표
이번 주차에서 무엇을 만드는지 1~2 문단.

## 결정 사항 (스택 / 아키텍처)
새로 정해진 기술 선택과 그 근거.

## 작업 체크리스트
- [ ] 논리 단위로 쪼갠 태스크. 각 태스크는 한 커밋 단위가 되도록.
- [ ] ...

## 검증
완료 기준 (시각적 합치, 동작 확인, 테스트 등).

## 회고 (완료 후 추가)
무엇이 잘 됐고 무엇이 다음 주차로 넘어가는지.
```

## CLAUDE.md와의 관계

- CLAUDE.md = 프로젝트 전범위 영구 규칙 (디자인 토큰, 스택 결정 등).
- plans/week-NN.md = 해당 주차의 일시적 작업 컨텍스트.
- 주차 진행 중 발견한 영구 규칙은 CLAUDE.md로 승격(Stop 훅이 일부 자동 처리).
