사용자가 스펙 수정 내용을 알려줬다. 아래 순서대로 진행해.

## 1단계: docs 문서 수정

`docs/DESIGN.md`, `docs/CHECKLIST.md` 중 관련된 파일을 읽고, 사용자가 알려준 스펙에 맞게 내용을 수정한다.
- 기존 내용 중 잘못 이해된 부분을 정정
- 새로운 스펙이 추가된 경우 해당 섹션에 반영
- CHECKLIST.md에서 영향받는 항목이 있으면 함께 수정

## 2단계: 코드 수정

수정된 스펙을 기준으로, 영향받는 소스 파일을 찾아 코드를 수정한다.
- 이미 구현된 부분만 수정 (미구현 항목은 문서 수정으로 충분)
- 수정 후 `pnpm build`로 타입 에러 없는지 확인

## 3단계: 결과 보고

어떤 문서와 코드를 수정했는지 간단히 요약해서 알려준다.
