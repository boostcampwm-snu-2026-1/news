# Newsstand

뉴스스탠드 디자인 시안을 바탕으로 만든 React 기반 데스크톱 뉴스 포털 프로젝트입니다.
2주차 기준으로 PDF 기획/디자인 문서를 Markdown 참고 문서로 정리하고, 상태 흐름 설계와 검증 체계를 포함한 UI 구현까지 진행했습니다.

## 실행 방법
```bash
npm install
npm run dev
```

## 검증 명령어
```bash
npm test
npm run build
npm run check
```
