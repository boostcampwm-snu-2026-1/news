# 뉴스스탠드 (Newsstand)

네이버 뉴스스탠드 서비스를 React + TypeScript + Vite 환경에서 구현하는 프로젝트입니다.

## 🚀 기술 스택
- **프레임워크**: React + Vite
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **상태 관리**: Zustand
- **데이터 패칭**: React Query (@tanstack/react-query)

## 📦 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```
