## Frame 05 — SBS Biz · 방송/통신 1/81 · 진행 중

언론사를 선택한 뒤 리스트 뷰 진입. 활성 탭의 프로그레스 바가 6초 주기로 진행.

### Field Tab (카테고리 탭)
| 종합/경제 | **방송/통신 1 / 81** | IT | 스포츠/연예 | 매거진/전문지 | 지역 |

- 활성 탭: 방송/통신, 진행률 약 50%, 카운터 `1 / 81`

### 헤드 행
- 워드마크: **SBS Biz**
- 편집 시간: 2026.01.14. 18:53 편집
- 버튼: `+ 구독하기`

### 기사 내용
**헤드라인**: 전기요금도 이제 '알림으로 다독다독'… 생활관리 습관 확산

**기사 리스트**:
- 출근길 드라마 끊김 이별? 지하철 와이파이, 살짝 더 빨라졌다
- "기다림이 폭신해졌어요" 동네 버스정류장 의자, 새 단장
- 데이터 걱정 내려놓기 실험… 통신사, '마음 편한 요금제' 선보여
- 잠들기 전에 보는 조용한 영상 한 편… OTT, 힐링 추천 기능 도입
- "길 잃지 않게 도와줄게요" 친절해진 환승 안내 목소리
- 퇴근 시간 맞춰 환하게 '찰칵'… 스마트 조명, 집이 먼저 반겨준다

**각주**: SBS Biz 언론사에서 직접 편집한 뉴스입니다.

## 주요 인터랙션 정리

### 구독 흐름
1. 전체 탭에서 셀 hover → `+ 구독하기` 버튼 노출
2. 클릭 → 구독 상태로 변경 → 탭 배지 +1
3. 구독 탭 진입 → 구독된 언론사만 그리드 표시
4. 구독 탭에서 셀 hover → `− 해지하기` 버튼 노출
5. 클릭 → 해지 → 탭 배지 -1

### 페이지네이션 흐름
1. 전체 탭: 3페이지 (24개씩)
2. 구독 탭: 구독 수에 따라 페이지 수 결정
3. 첫 페이지: 왼쪽 chevron 비활성 (opacity 0)
4. 마지막 페이지: 오른쪽 chevron 비활성 (opacity 0)

### 리스트뷰 진입 흐름
1. 언론사 셀 클릭
2. 그리드 → 열린 언론사 레이아웃으로 전환
3. 해당 언론사의 primary 카테고리 탭 활성화
4. 프로그레스 바 0부터 6초 카운트 시작
5. 6초 완료 → 같은 탭의 다음 언론사 (currentInTab + 1)
6. 탭 내 언론사 모두 소진 → 다음 탭으로 이동
7. 모든 탭 소진 → 첫 탭으로 루프
