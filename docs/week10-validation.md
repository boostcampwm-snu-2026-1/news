# 10주차 검증 기록

## 검증 대상

- 언론사 셀 클릭 시 리스트 뷰로 전환되는지 확인
- 구독 버튼 클릭이 리스트 오픈으로 이어지지 않는지 확인
- 리스트 닫기와 그리드 보기 버튼이 같은 상태 초기화를 수행하는지 확인
- FieldTab 진행률이 6초 단위로 기사와 분야를 순환하는지 확인
- 구독 탭이 비어 있을 때 빈 상태가 깨지지 않는지 확인
- 탭 키보드 이동과 포커스 표시가 유지되는지 확인
- 프로덕션 빌드가 통과하는지 확인

## 검증 방법

1. `npm run build`로 번들 생성 오류를 확인한다.
2. 개발 서버에서 다음 수동 시나리오를 확인한다.
   - 전체 언론사 첫 셀 클릭 후 리스트 화면 진입
   - 닫기 버튼 클릭 후 그리드 복귀
   - 구독하기 버튼 클릭 후 셀이 열리지 않고 구독 배지만 갱신
   - 내가 구독한 언론사 탭에서 해지 후 페이지 범위 유지
   - 리스트 화면에서 분야 탭을 마우스와 키보드로 변경
3. PR 본문에는 위 검증 대상과 실제 확인 결과를 기록한다.
