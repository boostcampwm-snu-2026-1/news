# 뉴스스탠드 디자인 명세

## 전체 레이아웃

- 전체 최대 너비: `1080px`, 수평 중앙 정렬 (`max-w-[1080px] mx-auto`)
- 배경: 흰색

```
┌─────────────────────────────────────────────────────┐
│  헤더 (로고 + 날짜)                                    │
├─────────────────────────────────────────────────────┤
│  속보 티커                                            │
├─────────────────────────────────────────────────────┤
│  탭 + 뷰 전환 버튼                                    │
├─────────────────────────────────────────────────────┤
│  [그리드 뷰] 언론사 그리드 (6열 × 4행) + 페이지네이션  │
│  [리스트 뷰] 카테고리 탭 + 언론사 뉴스 카드            │
└─────────────────────────────────────────────────────┘
```

---

## 헤더

- 좌측: 신문 아이콘 + **뉴스스탠드** 텍스트 (굵은 폰트)
- 우측: 날짜 (예: `2026. 01. 14. 수요일`)
- 배경: 흰색, 하단 구분선 없음

---

## 속보 티커

- 2개 언론사 동시 표시, 좌/우 각 하나씩 흰색 박스로 분리
- 각 박스: 언론사 이름(굵게, `font-bold`) + 기사 제목 한 줄
- 예시: `연합뉴스  [속보] 도심 공원 '조용한 독서존' 시범 운영… 시민 호응 …`
- 전체 티커 영역 배경: 흰색 (구분선으로 그리드와 분리)
- 텍스트 말줄임 처리 (`truncate`)

---

## 탭

두 개의 탭:

1. **전체 언론사** — 모든 언론사 표시
2. **내가 구독한 언론사** — 구독 중인 언론사만 표시, 우측에 구독 수 뱃지 (파란 원형)

- 활성 탭: 텍스트 굵게, 하단 border 강조
- 비활성 탭: 일반 텍스트, 회색 계열

탭 우측 끝에 뷰 전환 버튼:

- 리스트 뷰 아이콘 (`≡`)
- 그리드 뷰 아이콘 (`⊞`)
- 현재 선택된 뷰 아이콘 강조 표시, 미선택 아이콘 흐리게

---

## 그리드 뷰

### 구조

- **6열 × 4행** = 한 페이지당 최대 24개
- 각 셀은 동일한 크기, 테두리(`border`)로 구분
- 언론사 로고를 셀 중앙 정렬

### 언론사 로고

- 로고는 외부 이미지 파일 없이 **SVG 또는 JSX로 직접 구현**
- 디자인 이미지(`design/grid-all-press.png`)를 참고해 각 언론사의 색상, 폰트 스타일, 배경을 최대한 유사하게 재현
- 로고 유형 (디자인 이미지 기준):
  - 단색 텍스트: 서울경제, 데일리안, 세계일보, 조이뉴스24 등
  - 컬러 텍스트: 헤럴드경제(파랑+빨강), SBS Biz(파랑), 아이뉴스24(파랑), 파이낸셜뉴스, 시사저널e. 등
  - 컬러 배경 박스: 이데일리(빨간 배경 흰 텍스트), KBS WORLD(파란 배경 흰 텍스트)
  - 이탤릭 영문: *Insight*
  - 한자 혼용: 朝鮮日報
  - 영문: Korea JoongAng Daily, BUSINESS POST
- 각 로고는 `src/components/logos/` 아래 개별 컴포넌트로 분리 (`SeoulEconomyLogo.tsx` 등)
- 셀 중앙에 배치, 셀 너비/높이에 맞게 크기 조절

### 페이지네이션

- 우측 화살표 `>`: 다음 페이지
- 좌측 화살표 `<`: 이전 페이지
- 화살표는 그리드 좌우 바깥쪽에 수직 중앙 정렬
- 첫 페이지: 좌측 화살표 숨김 / 마지막 페이지: 우측 화살표 숨김

### 구독 인터랙션 (hover)

- 미구독 셀 hover 시: **"+ 구독하기"** 버튼 표시 (셀 중앙, 둥근 버튼)
- 구독 중인 셀 hover 시: **"− 해지하기"** 버튼 표시 (동일 디자인, 전체/구독 탭 모두)
- 나머지 빈 셀은 비어있는 채로 유지

## 리스트 뷰

참고 이미지: `design/list-view-progress.png`, `design/list-view-progress-end.png`

### 카테고리 탭

탭과 그리드 사이에 카테고리 탭 행이 추가됨:

| 종합/경제 | 방송/통신 | IT | 스포츠/연예 | 매거진/전문지 | 지역 |

- 활성 카테고리: 파란 배경, 흰 텍스트, `현재 언론사 순번 / 해당 카테고리 전체 언론사 수` 표시 (예: `방송/통신 1 / 5`)
- 비활성 카테고리: 회색 텍스트, 흰 배경, 클릭 시 해당 카테고리 첫 번째 언론사로 이동 + 프로그레스 바 재시작
- 활성 탭 하단에 **프로그레스 바** 표시
  - **6초 주기**로 좌→우 진행
  - 완료 시 해당 카테고리 내 다음 언론사로 자동 전환
  - 마지막 언론사면 첫 번째로 순환
- "내가 구독한 언론사" 탭 선택 시: 카테고리 탭 6개 유지, 각 카테고리에서 구독한 언론사만 순환

### 언론사 뉴스 카드

카테고리별로 현재 활성 언론사의 뉴스를 카드 형태로 표시:

```
┌────────────────────────────────────────────────────┐
│  [언론사 로고]  2026.01.14. 18:53 편집  [+ 구독하기] │
├──────────────┬─────────────────────────────────────┤
│              │  • 기사 제목 1                       │
│  헤드라인    │  • 기사 제목 2                       │
│  이미지      │  • 기사 제목 3                       │
│              │  • 기사 제목 4                       │
│              │  • 기사 제목 5                       │
│              │  • 기사 제목 6                       │
│              ├─────────────────────────────────────┤
│              │  OO언론사에서 직접 편집한 뉴스입니다. │
├──────────────┴─────────────────────────────────────┤
│  메인 기사 제목 (굵게, 하단)                         │
└────────────────────────────────────────────────────┘
```

- 상단: 언론사 로고 + 편집 날짜/시간 + 구독하기 버튼
- 좌측: 헤드라인 이미지 (placeholder 포함)
- 우측 상단: 기사 제목 목록 (bullet point 6개)
- 우측 하단: `"OO언론사에서 직접 편집한 뉴스입니다."` 텍스트
- 하단 (이미지 아래): 메인 기사 제목

### 페이지네이션

- 우측 `>` 화살표: 다음 언론사로 수동 이동
- 자동 전환(6초)과 수동 전환 모두 지원

## 목업 데이터

실제 데이터는 없으므로 디자인 이미지와 spec을 보고 Claude가 직접 생성한다. `src/data/mockData.ts` 에 작성.

### 언론사 목록 (`Press[]`)

디자인 이미지에 등장하는 언론사를 기반으로 30개 이상 구성. 각 언론사는 카테고리를 가짐.

```ts
interface Press {
  id: string;
  name: string;
  category: Category; // '종합/경제' | '방송/통신' | 'IT' | '스포츠/연예' | '매거진/전문지' | '지역'
  editedAt: string;   // 예: '2026.01.14. 18:53 편집'
  headlines: string[]; // 6개 기사 제목
  mainHeadline: string; // 메인 기사 제목 (카드 하단)
}
```

카테고리별 언론사 배분 (대략):
- 종합/경제: 서울경제, 데일리안, 아시아경제, 파이낸셜뉴스, 한국경제, 조선일보, 한겨레 등
- 방송/통신: SBS Biz, KBS WORLD, MBC 등
- IT: 아이뉴스24, 지디넷코리아 등
- 스포츠/연예: 스포츠서울, 스포츠동아 등
- 매거진/전문지: 헤럴드경제, Korea JoongAng Daily, Insight, 시사저널e., BUSINESS POST 등
- 지역: KNN, 한국농어촌방송 등

### 속보 티커 데이터 (`TickerItem[]`)

```ts
interface TickerItem {
  pressName: string;
  headline: string;
}
```

2개 항목. 디자인 이미지에 표시된 문구 참고.

### 헤드라인 이미지

리스트 뷰의 헤드라인 이미지는 실제 이미지 없이 **회색 placeholder** (`bg-gray-200` + `headline image` 텍스트)로 대체.

### 구독 상태 저장

구독 목록은 `localStorage`에 저장해 새로고침 후에도 유지된다.
