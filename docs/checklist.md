# 뉴스스탠드 개발 체크리스트

뉴스스탠드는 2주에 나누어 진행한다. 한 번에 전체 기능을 완성하려고 하지 않고, 화면을 구성하는 작은 기능 단위로 쪼개서 순서대로 개발한다.

## 전체 개발 범위

### 1주차 목표

뉴스스탠드의 기본 화면과 핵심 탐색 흐름을 만든다.

- [ ] HTML 기본 구조 만들기
- [ ] 디자인 시스템 색상과 기본 폰트 적용하기
- [ ] 상단 제목 영역 만들기
- [ ] 보기 전환 탭 만들기
- [ ] 언론사 데이터를 배열로 준비하기
- [ ] 전체 언론사 6x4 그리드 만들기
- [ ] 페이지네이션 UI 만들기
- [ ] 언론사 셀 hover 상태 만들기
- [ ] 언론사 선택 시 오른쪽 기사 영역 바꾸기
- [ ] 구독하기/해지하기 버튼의 기본 동작 만들기

### 2주차 목표

1주차 기능을 바탕으로 상태 관리와 세부 화면을 완성한다.

- [x] 내가 구독한 언론사만 보기
- [x] 리스트 보기 화면 만들기
- [x] 기사 탭 자동 진행 기능 만들기
- [x] 페이지 전환 직전 상태 다듬기
- [x] 반응형 또는 최소 화면 크기 대응하기
- [x] 접근성 속성 점검하기
- [x] 중복 코드 정리하기
- [x] 최종 디자인 디테일 맞추기

## 1주차 작은 기능 단위

### 1. 프로젝트 기본 파일 만들기

- [ ] `index.html` 만들기
- [ ] `styles.css` 만들기
- [ ] `script.js` 만들기
- [ ] 세 파일이 서로 연결되는지 확인하기

### 2. 화면 뼈대 만들기

- [ ] 전체 페이지를 감싸는 `main` 영역 만들기
- [ ] 상단 제목과 구독 수 영역 만들기
- [ ] 탭 영역 만들기
- [ ] 언론사 그리드 영역 만들기
- [ ] 기사 리스트 영역 만들기

### 3. 디자인 토큰 적용하기

- [ ] 색상을 CSS 변수로 정리하기
- [ ] 배경색, 글자색, 선 색상 적용하기
- [ ] 버튼과 셀의 기본 크기 맞추기
- [ ] 카드형 장식보다 얇은 선 중심으로 화면 구분하기

### 4. 언론사 그리드 만들기

- [ ] 언론사 이름, 분류, 표시 스타일 데이터를 배열로 만들기
- [ ] JavaScript로 언론사 셀을 화면에 그리기
- [ ] 6열 그리드로 배치하기
- [ ] 한 페이지에 24개씩 보이도록 나누기

### 5. 페이지네이션 만들기

- [ ] 현재 페이지 번호 표시하기
- [ ] 이전 페이지 버튼 만들기
- [ ] 다음 페이지 버튼 만들기
- [ ] 현재 페이지를 나타내는 진행 표시 만들기

### 6. 언론사 선택 기능 만들기

- [ ] 언론사 셀을 클릭하면 선택 상태 저장하기
- [ ] 선택된 셀에 강조 스타일 적용하기
- [ ] 오른쪽 영역에 선택한 언론사 이름 표시하기
- [ ] 선택한 언론사에 맞는 기사 제목 목록 표시하기

### 7. 구독 기본 기능 만들기

- [ ] 구독 상태를 저장할 자료구조 만들기
- [ ] 구독하기 버튼 클릭 시 구독 상태 추가하기
- [ ] 해지하기 버튼 클릭 시 구독 상태 제거하기
- [ ] 상단 구독 수 갱신하기
- [ ] 구독 중인 셀에 다른 상태 표시하기

## 1주차 완료 기준

- [ ] 브라우저에서 `index.html`을 열었을 때 화면이 깨지지 않는다.
- [ ] 전체 언론사 그리드가 6x4 형태로 보인다.
- [ ] 이전/다음 버튼으로 페이지를 이동할 수 있다.
- [ ] 언론사를 클릭하면 오른쪽 기사 영역이 바뀐다.
- [ ] 구독하기와 해지하기가 동작한다.
- [ ] 구독 수가 화면에 반영된다.
