# 뉴스스탠드 체크리스트

## 1주차
- [ ] 언론사 데이터 하드코딩 하기: 한 100개 정도
- [ ] '전체 언론사' 페이지에 언론사 목록 만들기: 가로 6줄, 세로 4줄 / 언론사 목록은 각 언론사의 마크(이미지) / 언론사 목록은 그리드 형태 / 상단에 '전체 언론사', '내가 구독한 언론사' 표시 두기
- [ ] 페이지 넘김 기능 만들기
  - [ ] '<'와 '>'로 페이지 넘기기
  - [ ] <를 누르면 오른쪽으로 슬라이드, >를 누르면 왼쪽으로 슬라이드
  - [ ] 1페이지에서는 <를, 마지막 페이지에서는 >를 누를 수 없게 만든다.
  - [ ] 하단에 현재 페이지 표시 (1/4 등)
- [ ] 언론사 위에 hover 하면 '구독'과 '기사보기'가 뜨게 하기
- [ ] '구독' 클릭 시 구독 언론사 저장 (새로고침 되어도 상태 유지)
