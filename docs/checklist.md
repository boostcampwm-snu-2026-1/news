## 📊 체크리스트 사용 방법

### 개발 프로세스 (각 항목마다)
```
1. 설계 단계
   - GitHub Copilot에게 "이 항목 구현하는 방법이 뭘까요?"라고 질문
   - 컴포넌트 구조, props, 상태 관리 방식 논의

2. 구현 단계
   - GitHub Copilot이 코드 생성
   - 디자인 시스템 준수 확인

3. 리뷰 단계
   - 코드 검토: 가독성, 로직, 디자인 준수
   - 버그 확인: 호버, 클릭, 페이지네이션 동작

4. 커밋 단계
   - 형식: feat: #[번호] [기능명]
   - 확인내용 + 이해 안 됐던 부분 기록
```

### 커밋 메시지 예시
```
feat: #4 Header + Ticker 컴포넌트
  - 확인내용: 헤더 레이아웃 완성, 티커 2레인 회전 애니메이션 구현
  - 이해 안 됐던 부분: cubic-bezier(.4,0,.2,1) 타이밍 함수 이유 확인
```
