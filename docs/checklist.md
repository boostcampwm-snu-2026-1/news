# 뉴스스탠드 개발 체크리스트

> 뉴스스탠드는 여러 언론사의 뉴스를 한 화면에서 탐색하고, 관심 있는 언론사를 구독할 수 있는 웹 포털입니다.

---

## 1주차 — 화면 뼈대 만들기

> 이번 주 목표: 버튼을 눌러도 아무 일도 안 일어나도 괜찮아요. 일단 기획서와 똑같이 **보이는** 화면을 만드는 것이 목표입니다.

---

### #1 디자인 토큰(색상·폰트·간격) 정의하기

화면 전체에서 쓰는 색상, 글자 크기, 여백을 한 곳에 몰아서 정의합니다.  
예를 들어 `--color-accent: #7890E7` 처럼 CSS 변수로 만들어 두면, 나중에 색을 바꿀 때 한 줄만 고쳐도 전체가 바뀝니다.

- **무엇을 만드나요?** `src/styles/tokens.css` 파일 하나
- **완료 기준:** 색상·폰트·간격 값이 변수로 선언돼 있고, 다른 파일에서 `var(--color-ink)` 처럼 가져다 쓸 수 있다

- [ ] 색상 변수 (ink, sub, line, accent, accent-deep 등) 선언
- [ ] 폰트 변수 (Pretendard, IBM Plex Mono, Noto Serif KR) 선언
- [ ] 간격·반경 변수 (8px 배수, pill 반경 등) 선언

---

### #2 헤더 만들기

화면 맨 위에 있는 "뉴스스탠드" 타이틀과 오늘 날짜를 보여주는 영역입니다.

- **무엇을 만드나요?** `<Header>` 컴포넌트
- **완료 기준:** 왼쪽에 신문 아이콘 + "뉴스스탠드", 오른쪽에 "2026. 01. 14. 수요일" 형식의 날짜가 보인다

- [ ] 오늘 날짜를 "YYYY. MM. DD. 요일" 형식으로 계산해서 표시
- [ ] 아이콘과 타이틀 왼쪽, 날짜 오른쪽 레이아웃 (flexbox space-between)

---

### #3 뉴스 티커 만들기

헤더 아래에서 뉴스 헤드라인이 자동으로 바뀌며 흘러가는 띠 영역입니다.  
두 줄이 나란히 있고, 3.2초마다 다음 기사 제목으로 바뀝니다.

- **무엇을 만드나요?** `<Ticker>` 컴포넌트
- **완료 기준:** 언론사명 + 기사 제목이 두 줄로 보이고, 일정 시간마다 자동으로 다음 기사로 바뀐다

- [ ] 언론사명(굵게)과 기사 제목(일반)을 나란히 한 줄에 표시
- [ ] 두 레인이 서로 다른 타이밍으로 교체되도록 구현 (동시에 바뀌지 않게)
- [ ] 기사 제목이 너무 길면 `...`으로 잘리게 처리

---

### #4 탭바 + 뷰 전환 버튼 만들기

"전체 언론사" / "내가 구독한 언론사" 탭과, 오른쪽의 그리드·리스트 뷰 전환 버튼입니다.

- **무엇을 만드나요?** `<TabBar>` 컴포넌트
- **완료 기준:** 탭을 클릭하면 활성 탭이 굵어지고, "내가 구독한 언론사" 탭 옆에 구독 수 배지(파란 동그라미)가 보인다

- [ ] 탭 두 개 (전체 / 구독) 렌더링, 클릭 시 활성 상태 전환
- [ ] 구독 수 배지: 파란 원 안에 숫자 표시
- [ ] 오른쪽에 그리드 아이콘 / 리스트 아이콘 버튼 배치

---

### #5 언론사 이름(워드마크) 컴포넌트 만들기

각 언론사 이름은 이미지가 아니라 **스타일이 적용된 텍스트**로 표현합니다.  
예: 조선일보는 세리프 폰트, KBS WORLD는 파란 배경 칩, 아시아경제는 끝에 빨간 깃발 아이콘.

- **무엇을 만드나요?** `<PressWordmark>` 컴포넌트
- **완료 기준:** 언론사 데이터 객체(이름, 색상, 폰트 종류 등)를 넘기면 해당 스타일로 렌더링된다

- [ ] 기본 sans-serif / serif 폰트 분기 처리
- [ ] 이탤릭, 자간(letter-spacing), 색상, 밑줄 props 반영
- [ ] 배경 칩(KBS WORLD 등) 및 깃발 아이콘(아시아경제) 처리

---

### #6 언론사 그리드(6×4) 만들기

언론사들이 6열 4행 격자로 나열되는 메인 영역입니다.  
한 페이지에 24개씩 표시되고, 3페이지(총 72개)가 있습니다.

- **무엇을 만드나요?** `<PressGrid>` 컴포넌트
- **완료 기준:** 언론사 이름이 6×4 격자에 고르게 배치되고, 각 칸의 크기와 간격이 기획서와 비슷하다

- [ ] CSS Grid로 6열 4행 레이아웃 구성 (gap 1px → 구분선 역할)
- [ ] 각 셀 안에 `<PressWordmark>` 배치, 가운데 정렬
- [ ] 페이지당 24개 언론사 목 데이터로 채우기

## 2주차 — 인터랙션 붙이기

> 이번 주 목표: 클릭하고 마우스를 올렸을 때 실제로 반응하는 화면을 완성합니다.

---

### #7 그리드 셀 마우스 올림(hover) 효과 만들기

언론사 이름 위에 마우스를 올리면 이름이 사라지고 "구독하기" 또는 "해지하기" 버튼이 나타납니다.

- **완료 기준:** 마우스를 올리면 구독 버튼이 나타나고, 마우스를 치우면 다시 이름이 보인다. 키보드 탭으로 포커스 이동해도 동일하게 동작한다

- [ ] CSS `:hover`로 워드마크 숨기고 pill 버튼 표시
- [ ] 키보드 접근도 `:focus-within`으로 동일하게 처리

---

### #8 페이지 넘기기(← →) 만들기

그리드 양쪽의 화살표 버튼으로 다음/이전 페이지로 이동합니다.  
첫 페이지에서 왼쪽 화살표는 보이지 않고, 마지막 페이지에서 오른쪽 화살표도 보이지 않습니다.

- **완료 기준:** 화살표 클릭 시 다음 24개 언론사로 전환되고, 첫/마지막 페이지에서 해당 방향 화살표가 사라진다

- [ ] 현재 페이지 상태 관리, 버튼 클릭 시 페이지 변경
- [ ] 첫 페이지: 왼쪽 화살표 `opacity: 0` / 마지막 페이지: 오른쪽 화살표 `opacity: 0`

---

### #9 구독·해지 기능 만들기

"구독하기"를 누르면 "내가 구독한 언론사" 탭에 해당 언론사가 추가되고, 배지 숫자가 올라갑니다.

- **완료 기준:** 구독 후 탭 전환 시 해당 언론사가 구독 탭에 보이고, 해지하면 사라진다

- [ ] 구독 중인 언론사 ID를 상태(Set)로 관리
- [ ] 구독/해지 버튼 클릭 시 상태 업데이트 → 탭 배지 숫자 자동 반영
- [ ] "내가 구독한 언론사" 탭에서는 구독한 언론사만 그리드에 표시

---

### #10 언론사 클릭 시 기사 목록 보기 만들기

언론사를 클릭하면 그리드 대신 해당 언론사의 기사 목록 화면으로 전환됩니다.  
상단에 카테고리 탭이 있고, 6초마다 자동으로 다음 카테고리 탭으로 넘어갑니다.

- **완료 기준:** 언론사 클릭 → 기사 목록 보임. 탭 안의 파란 진행 바가 6초 동안 채워지고, 가득 차면 다음 탭으로 이동한다

- [ ] 언론사 클릭 시 `opened` 상태 변경 → 그리드 대신 `<PressOpen>` 렌더링
- [ ] 카테고리 탭 진행 바: `setInterval`로 100ms마다 progress 증가, 6000ms에 탭 전환
- [ ] 탭이 모두 끝나면 다음 언론사로 자동 이동

---

### #11 기사 목록 화면(리스트 뷰) 만들기

언론사를 선택했을 때 보이는 상세 화면입니다. 왼쪽에 헤드라인 이미지, 오른쪽에 기사 6개 목록이 나옵니다.

- **완료 기준:** 언론사명, 편집 시각, 구독 버튼, 헤드라인 이미지 플레이스홀더, 기사 6개 목록이 기획서 레이아웃과 일치한다

- [ ] 좌(이미지 영역 340px) + 우(기사 목록) 2단 레이아웃
- [ ] 기사 항목: 앞에 작은 사각형 불릿 + 기사 제목
- [ ] 하단 "○○ 언론사에서 직접 편집한 뉴스입니다." 문구

---

### #12 접근성 마무리

마우스 없이 키보드만으로도 모든 기능을 사용할 수 있어야 합니다.  
스크린리더 사용자도 "지금 몇 번째 탭인지", "구독 중인 언론사가 몇 곳인지" 알 수 있어야 합니다.

- **완료 기준:** 탭 키로 모든 버튼에 포커스 이동 가능, 스크린리더에서 탭 상태와 배지 숫자를 읽어준다

- [ ] 탭바에 `role="tablist"`, 각 탭에 `role="tab"` + `aria-selected` 추가
- [ ] Chevron 버튼에 `aria-label="이전 페이지"` / `"다음 페이지"` 추가
- [ ] 구독 배지에 `aria-label="구독 중인 언론사 9곳"` 추가
