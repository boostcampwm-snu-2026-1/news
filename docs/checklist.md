# 뉴스스탠드 체크리스트

## 1주차
- [x] 언론사 데이터 하드코딩 하기: 한 100개 정도
- [x] '전체 언론사' 페이지에 언론사 목록 만들기: 가로 6줄, 세로 4줄 / 언론사 목록은 각 언론사의 마크(이미지) / 언론사 목록은 그리드 형태 / 상단에 '전체 언론사', '내가 구독한 언론사' 표시 두기
- [x] 페이지 넘김 기능 만들기
  - [x] '<'와 '>'로 페이지 넘기기
  - [x] <를 누르면 오른쪽으로 슬라이드, >를 누르면 왼쪽으로 슬라이드
  - [x] 1페이지에서는 <를, 마지막 페이지에서는 >를 누를 수 없게 만든다.
  - [x] 하단에 현재 페이지 표시 (1/4 등)
- [x] 언론사 위에 hover 하면 '구독'과 '기사보기'가 뜨게 하기
- [x] '구독' 클릭 시 구독 언론사 저장 (새로고침 되어도 상태 유지)
- [x] 언론사 이미지를 한번에 다 다운받아서 넣을 수 있게 하기
- [x] 필요없는 이미지 파일 (기존에 깔려있던 파일) 없애기
- [x] 넘기는 화살표 크기를 조금 더 키우고, 공간을 조금 더 추가하기
- [x] 화살표 넘겨서 언론사가 바뀌는 부분이 화면 깜빡임 없이 자연스럽게 되게 하기

    - [x]  '기사보기' 버튼에 해당 url 연결하기
- [x] '내가 구독한 언론사' 탭 화면에 구독 언론사 목록 렌더링하기

  - [x] '내가 구독한 언론사' 탭에서는 모든 셀 hover 시 '해지하기'와 '기사보기' 표시
