# 뉴스스탠드 개발 체크리스트

## 체크리스트 작성 방식
- 형식은 `번호 + 작업명 + 목적 + 주차 + 상태`로 관리한다.
- 모든 커밋 메시지는 관련 체크리스트 번호를 `#번호` 형태로 참조한다.
- `이번주` 표시는 1주차 우선 개발 범위다.

## 이번주 학습 목표
- 일반적인 소프트웨어 개발 흐름을 직접 문서화하고 작은 기능 단위로 나눠서 개발한다.
- AI를 동료처럼 활용하며 설계, 구현, 리뷰 흐름을 반복한다.
- Gemini, Claude 같은 AI Agent 도구를 사용할 때 어떤 정보를 먼저 정리해야 하는지 익힌다.

## 이번주 개발 범위
- 이번주에는 `#1`, `#2`, `#3`, `#4`, `#5`, `#6`, `#12`를 우선 진행한다.
- 목표는 문서 기반 개발 준비를 끝내고, 뉴스스탠드의 기본 레이아웃과 핵심 카드 UI를 착수 가능한 수준으로 만드는 것이다.

## 체크리스트 활용 메모
- 한 번에 여러 기능을 구현하기보다 번호 하나씩 끝내는 방식으로 진행한다.
- 번호는 작업 추적뿐 아니라 커밋 메시지, PR 설명, AI 요청 범위를 맞추는 기준으로 사용한다.
- 기획이 바뀌면 체크리스트의 상태와 우선순위도 함께 갱신한다.
