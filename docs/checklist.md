# 뉴스스탠드 개발 체크리스트

## 이번 주 개발 범위

이번 주는 `#1`부터 `#7`까지를 우선 개발 범위로 선정한다. 이 범위는 첫 화면 진입부터 전체 언론사 그리드와 구독/해지 상호작용까지 포함하므로, 이후 리스트 뷰와 자동 전환 기능을 붙이기 전에 화면의 기본 골격을 검증할 수 있다.

선정 기준은 다음과 같다.

- PDF 01번 기본 상태를 Chrome에서 확인 가능한 수준까지 구현한다.
- PDF 02번 hover 상태를 구현하기 전에 필요한 상태, 데이터, 그리드 구조를 먼저 만든다.
- 리스트 뷰, 81개 자동 진행, 페이지 전환은 기본 골격 검증 후 다음 범위로 넘긴다.

## 개발 workflow

1. 기능 번호를 하나 고른다.
2. 관련 PDF 항목과 Next.js 문서를 확인한다.
3. 작은 구현 단위로 코드를 수정한다.
4. `npm run lint`를 실행한다.
5. Chrome headless screenshot으로 화면을 확인한다.
6. 커밋 본문에 확인내용과 이해가 안 됐던 부분을 기록한다.

## 커밋 로그 형식

```txt
feat: #3 뉴스 카드 컴포넌트

- 확인내용: 컴포넌트 배치 확인, 구조가 복잡해서 컴포넌트 분리 추가 진행
- 이해 안 됐던 부분: useCallback 왜 사용했는지 확인함
```
