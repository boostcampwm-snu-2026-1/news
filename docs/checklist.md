# 뉴스스탠드 개발 체크리스트

## 이번 주 개발 범위

이번 주는 `#11`부터 `#18`까지를 2주차 범위로 선정한다. 초점은 기사 리스트 뷰와 자동 진행을 붙이는 것 자체보다, 그 구현을 지탱할 상태 흐름 설계와 검증 체계를 먼저 고정하는 데 있다.

선정 기준은 다음과 같다.

- 리스트 뷰 상태를 reducer 또는 동등한 전이 모델로 설명 가능해야 한다.
- 컴포넌트 계층별 책임과 props 경계를 문서로 남긴다.
- 구현 후에는 edge case를 먼저 도출하고, lint/build/test/UI 확인으로 검증 결과를 남긴다.

## 개발 workflow

1. 기능 번호를 하나 고른다.
2. 관련 PDF 항목과 Next.js 문서를 확인한다.
3. 작은 구현 단위로 코드를 수정한다.
4. `npm run lint`를 실행한다.
5. `npm run test`, `npm run build`까지 필요한 범위를 검증한다.
6. Chrome에서 실제 hover, 클릭, 탭 전환, 자동 진행을 확인하고 필요 시 headless screenshot을 남긴다.
7. 커밋 본문에 기능 번호, 확인내용, 이해가 안 됐던 부분을 기록한다.
