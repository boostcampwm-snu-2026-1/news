# 참고 문서 관리

## 현재 상태
- 저장소에는 아직 기획서와 디자인시스템 원본 PDF가 포함되어 있지 않다.
- 따라서 지금은 `docs/checklist.md`, `CLAUDE.MD`, PR 기록을 기준으로 개발 범위를 관리한다.

## PDF가 추가되면 할 일
1. `뉴스스탠드-기획디자인` PDF를 Markdown으로 변환해 `docs/references/newsstand-planning.md`로 저장한다.
2. `뉴스스탠드-디자인시스템` PDF를 Markdown으로 변환해 `docs/references/newsstand-design-system.md`로 저장한다.
3. 변환된 문서를 읽고 체크리스트, 스타일 기준, 컴포넌트 설계를 업데이트한다.

## 작업 원칙
- 스타일과 UI 결정은 가능한 한 Markdown으로 변환된 참고 문서를 기준으로 한다.
- 기획이 바뀌면 변환 문서와 체크리스트를 함께 수정한다.
