# 뉴스스탠드 기획서 변환본

원본: `/Users/donghyun/Downloads/1776841621755_뉴스스탠드-기획디자인.pdf`

## 문서 개요
- 데스크톱 중심 웹 포털 형태의 뉴스스탠드 서비스다.
- 전체 언론사를 6x4 그리드로 탐색하고, 구독/해지를 관리하며, 언론사 선택 시 기사 리스트 뷰로 전환한다.
- 상단에는 날짜, 헤더, 자동 롤링 뉴스 티커가 항상 노출된다.

## 화면 흐름 요약

### 1. 기본 상태
- 진입 직후에는 `전체 언론사` 탭과 `그리드 보기`가 기본 상태다.
- 언론사 24개를 한 페이지에 6x4로 배치한다.
- 상단에는 날짜와 두 줄짜리 자동 뉴스 티커가 고정된다.

### 2. hover 시 구독 액션
- `전체 언론사` 탭에서 셀 hover 시 `+ 구독하기` 버튼이 나타난다.
- `내가 구독한 언론사` 탭에서는 hover 시 `- 해지하기` 버튼이 나타난다.
- 키보드 포커스에서도 같은 액션이 보여야 한다.

### 3. 구독 탭
- `내가 구독한 언론사` 탭에는 구독 중인 언론사만 채워진다.
- 구독 개수는 배지 형태로 표시된다.
- 구독 수가 24개를 넘으면 별도의 페이지네이션이 필요하다.

### 4. 페이지네이션
- 전체 언론사는 총 72개를 기준으로 3페이지 구성이다.
- 좌우 chevron으로 페이지 이동한다.
- 첫 페이지와 마지막 페이지에서는 각 방향 버튼이 비활성화된다.

### 5. 기사 리스트 뷰
- 언론사 셀을 클릭하면 오픈 뷰로 전환된다.
- 상단에는 카테고리 탭이 있고, 현재 카테고리의 진행 바가 6초 주기로 채워진다.
- 좌측에는 대표 이미지와 현재 헤드라인, 우측에는 기사 리스트가 표시된다.

### 6. 자동 전환 규칙
- 활성 카테고리의 진행 바가 100%가 되면 같은 카테고리의 다음 기사로 이동한다.
- 카테고리의 마지막 기사까지 도달하면 다음 카테고리로 넘어간다.
- 마지막 카테고리의 마지막 기사까지 끝나면 다시 첫 카테고리부터 반복한다.

## 핵심 기능 요구사항
- 언론사 구독/해지
- 전체/구독 탭 전환
- 그리드/리스트 전환
- 오픈 뷰 자동 진행
- 페이지네이션
- 반응형 축소 대응
- 키보드 접근성

## 2주차 구현에 반영한 내용
- 72개 언론사 목업 데이터를 만들어 3페이지 그리드 구조를 맞췄다.
- 구독 세트와 현재 뷰 상태를 앱 최상위 상태로 올렸다.
- 오픈 뷰의 자동 진행은 순수 상태 전이 함수로 분리해 테스트 가능하게 만들었다.
