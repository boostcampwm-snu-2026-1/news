## 디자인 원칙
- 장식보다 명확함: 과한 그라데이션과 그림자 대신 얇은 선과 밀도 높은 타이포그래피로 구분한다.
- 타이포그래피 중심 브랜딩: 언론사 로고를 이미지 대신 워드마크처럼 다룬다.
- 포인트 컬러 최소화: `#7890E7`은 구독 수 배지와 활성 탭 진행 상태에만 사용한다.
- Dense and calm: 화면에는 많은 정보를 담되 여백과 정렬로 안정감을 만든다.

## 색상 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `ink` | `#14212B` | 본문, 강한 텍스트, 주요 선 |
| `sub` | `#5F6E76` | 보조 텍스트, 날짜, 메타 정보 |
| `mute` | `#879298` | 비활성 탭, 보조 아이콘 |
| `line` | `#D2DAE0` | 1px 구분선, 카드 보더 |
| `soft` | `#F5F7F9` | 티커, 열려 있는 탭 배경 |
| `card` | `#FFFFFF` | 카드, 셀, 버튼 바탕 |
| `page` | `#FEFEFE` | 전체 페이지 배경 |
| `accent` | `#7890E7` | 활성 상태, 구독 배지 |
| `accent-deep` | `#4362D0` | 활성 탭 진행 바 |

## 타이포그래피
- 기본 폰트: `Pretendard Variable`, `Pretendard`, `Noto Sans KR`
- 숫자/카운터: `IBM Plex Mono`
- 세리프 포인트: `Noto Serif KR`
- 본문은 16px 중심, 메타 정보는 12px 중심으로 유지한다.

## 레이아웃 규칙
- 데스크톱 기준 캔버스는 1280px 폭, 실제 콘텐츠 열은 930px 폭이다.
- 좌우 chevron은 콘텐츠 열 바깥에서 동작한다.
- 그리드는 6열 4행이며 셀 간격은 1px 선으로 처리한다.

## 컴포넌트 규칙

### 헤더
- 좌측은 브랜드, 우측은 오늘 날짜를 배치한다.

### 티커
- 두 개의 동일 폭 레인을 사용한다.
- 3.2초 주기로 교체하며, hover/focus 시 일시정지한다.
- `prefers-reduced-motion` 환경에서는 자동 회전을 멈춘다.

### 탭 바와 보기 토글
- `전체 언론사`, `내가 구독한 언론사` 탭이 있다.
- 활성 탭은 굵기와 색으로 구분한다.
- 리스트/그리드 토글 아이콘은 우측에 배치한다.

### 그리드 셀
- 기본 상태에서는 언론사 워드마크만 보여준다.
- hover/focus 시 구독/해지 pill이 나타난다.
- 셀 배경은 hover 시 `soft`로 바뀐다.

### 오픈 뷰
- 상단에 카테고리 탭 스트립이 있다.
- 활성 탭은 `accent` 배경 + `accent-deep` 진행 오버레이를 가진다.
- 본문은 좌측 대표 이미지와 우측 기사 리스트로 구성된다.

## 접근성 메모
- 탭 그룹은 `role="tablist"`와 `role="tab"`을 사용한다.
- chevron은 `button`과 `aria-label`을 가진다.
- hover 전용 제어는 focus 상태에서도 보여야 한다.
- 모션 감소 환경을 존중해야 한다.

## 구현 시 반영 포인트
- 색상은 CSS 변수로 옮긴다.
- 언론사 워드마크는 데이터 기반 컴포넌트로 만든다.
- 자동 진행은 컴포넌트 내부에 숨기지 말고 상태 전이 규칙으로 분리한다.
